### Build Multi-Language Files

```bash
python build_langs.py
```

This script reads `index.html` as the template, applies translations from `i18n.js`, and generates all language-specific HTML files. Each file includes:
- Fully translated text in the target language
- Language switcher links (not dropdown) pointing to other language files
- `lang-link-active` class on the current language
- RTL support for Arabic (`dir="rtl"`)

## EACO Daily Agent v4.0

### Features

- **15 Earning Strategies**: From liquidity mining to AI content factories
- **Multi-Source Price Fetching**: GeckoTerminal > DexScreener > Jupiter > Fallback
- **On-Chain Data**: Solana RPC via PublicNode (token supply, holders, epoch)
- **Meteora DLMM Pool Monitoring**: E-USDT and E-SOL pool status
- **Price Alerts**: SOL 24h change >10%, DEX spread >5%, low liquidity warning
- **HTML Visual Report**: Card-based dashboard with strategy tables
- **Multi-Currency Display**: USD, USDT, SOL, EACO, USDC
- **Auto-Copy to Website**: Reports automatically copied to `eaco-app/` directory
- **CLI Flags**: `--quiet`, `--json-only` for cron integration
- **Error Resilience**: Graceful fallbacks for all API failures

### Usage

```bash
# Normal run (generates JSON + HTML report)
python eaco_daily_agent.py

# Quiet mode (minimal output)
python eaco_daily_agent.py --quiet

# JSON-only output (for piping to other tools)
python eaco_daily_agent.py --json-only

# Windows Task Scheduler
run_daily.bat
```
